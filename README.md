# 生命树 · The Tree of Life 简体中文翻译

原作者 **pg132** · 独立汉化 **somnis7**

基于英文原版 2.068 的非官方汉化。游戏玩法和数值保持原版；翻译使用独立文件维护。

**汉化仍在完善，尚未覆盖全游戏。** 已加入基础菜单、设置、常用资源名，正常模式下生命、氨基酸、蛋白质、DNA、细胞、干细胞、组织阶段的大部分升级与里程碑说明，以及反挑战、干细胞挑战和代币 II 的效果说明。其他阶段、困难／极限模式的专属文本仍待翻译、校对。

右下角可切换中英文，以及“紧凑／标准／大”三档字号，显示偏好会自动保存。使用系统字体，无需下载在线字体。

## 参与汉化

基础词条见 [js/i18n/zh-CN.js](js/i18n/zh-CN.js)；生命、蛋白质和 DNA 见 [molecular.js](js/i18n/molecular.js)；细胞和组织见 [progression.js](js/i18n/progression.js)。详细步骤和术语约定见 [汉化指南](docs/translation.md)。

购买项使用“中文＋英文原名”，例如“全能 Totipotent”和“多能 Multipotent”，便于与公式及攻略对照。所有数值、公式、内部标识和存档字段保持原文。

## 存档

支持按原游戏方式导入、导出 2.068 存档。网页存档按域名保存；换到自己的站点后需要手动导入。首次测试请导出备份，并使用副本。不要向仓库上传个人存档。
