# 如何继续汉化

## 修改哪个文件

基础菜单和通用词条编辑 `js/i18n/zh-CN.js`；生命、氨基酸、蛋白质、DNA 和反挑战编辑 `js/i18n/molecular.js`；细胞、干细胞、组织编辑 `js/i18n/progression.js`。文件采用 UTF-8 编码。

- `exact`：完整句子和按钮，例如 `'Save': '保存'`。优先级最高。
- `terms`：完整英文单词组成的资源名。只替换完整单词；较长词组优先。
- `rules`：带动态数值的整段文本。正则必须以 `^` 开始、`$` 结束，使用 `$1` 等保留数值。

词条不含前后的空白；运行层会保留原来的空白。带 HTML 的文本按文本节点翻译，标签、颜色、公式上标和链接保持原样。一句话若被 `<b>` 等标签隔开，应分别翻译各个片段。

新增词条后保存文件、刷新页面。右下角可切换英文核对原文，并切换“紧凑／标准／大”三档字号。字号偏好独立保存，不影响游戏进度。

目前覆盖基础界面、资源名，以及正常模式生命至组织阶段的大部分升级、里程碑和挑战说明，**并未完成全游戏汉化**。不要将正常模式的数值文案直接套用到困难／极限模式。

`Reward:`、`Currently:`、`Next:`、`Cost:`、`Goal:` 的标签会单独翻译，其后的完整句子仍会继续查找词条；通常只需添加不含标签的正文。若一句话在公式上标两侧被 HTML 拆开，则按实际文本片段添加词条。

## 术语约定

| 英文 | 中文显示 | 说明 |
| --- | --- | --- |
| Omnipotent | 万能 Omnipotent | 游戏中的独立购买项名称；不等同于生物学 totipotency |
| Totipotent | 全能 Totipotent | 保留英文，便于区分 |
| Pluripotent | 多潜能 Pluripotent | 与 Multipotent 区分 |
| Multipotent | 多能 Multipotent | 干细胞购买项 |
| Oligopotent | 寡能 Oligopotent | 干细胞购买项 |
| Primary / Secondary / Tertiary | 初级／次级／三级挑战＋英文 | 保留原名，便于攻略对照 |
| Up / Down / Charm / Strange / Top / Bottom Quark | 上／下／粲／奇／顶／底夸克＋英文 | 使用粒子物理学常见译名 |
| prestige / reset | 重置 | 对照具体机制，不一律译为“声望” |
| multiply | 乘以／变为原来的…倍 | 与指数、幂区分 |
| raise … to … | 取…次方 | 必须明确底数和指数 |
| bulk buy / buy max | 批量购买／购买至上限 | 区分固定批量与最大可买数量 |
| OOM | 数量级 OOM | 保留计数符号，如 OOM/s；不要改数值 |
| softcap / hardcap | 软上限／硬上限 | 软上限通常减缓增长，硬上限直接截断 |
| base cost / cost base / cost exponent | 初始花费／花费底数／花费指数 | 必须区分公式中的不同位置 |
| Life / Life Points | 生命／生命点 | 两种资源，不混用 |

优先翻译正常模式；涉及困难、极限模式的说明必须分别校对。公式、希腊字母、HTML 标签、快捷键和游戏内部键名不翻译。

## 收集漏译

在游戏里打开对应页面，开发者工具控制台执行 `LifeI18n.getMissing()`，即可查看本次访问记录到的待校对短文本。它只是候选列表，可能包含公式或专有名词，不是准确覆盖率。不会上传任何数据。

运行层不自动记录带数字、超过 240 字符的文本；可直接在英文源码中搜索完整说明，为其添加 `rules` 或分段词条。

## 运行与校验

安装 Node.js 后，在项目目录执行：

```sh
node tools/serve.cjs
```

打开 `http://127.0.0.1:8080/`。静态服务器仅监听本机；不同端口、不同域名下的存档相互独立。

```sh
node --test tests/translation.test.cjs
```

每轮翻译至少检查：新游戏、设置页、显示公式的购买项、含颜色的升级说明、中英文切换，以及导入存档。自己的正式存档请先导出备份，测试使用副本。
